## Main Features
<a id="main-features"></a>

### Core Functionality
- **Digital Terrain Models Creation** — Easily create and manage digital terrain models for any project with intuitive tools that streamline the design process.
- **DXF and ASCII Compatibility** — Import and manipulate files in DXF format as well as ASCII points, allowing for seamless integration into existing workflows.
- **Triangulation and 3D Viewing** — Perform triangulation to visualize terrain models in three dimensions, facilitating better understanding and presentation of topographic data.
- **MDT Exporting** — Export your models in MDT format, making it compatible with various other applications and ensuring wider usability.
- **Direct AutoCAD Readings** — Streamline your workflow with the ability to perform direct readings from AutoCAD, enhancing productivity and accuracy.

### Advanced Capabilities
- **Ground Slopes Calculations** — Calculate ground slopes and terraces with customizable variable and fixed quotes, providing detailed analysis tailored to your needs.
- **Dynamic Map Calculations** — Generate dynamic calculations from transverse profiles to create accurate representations of terrain changes.
- **TOP File Support** — Work with TOP files and blocks, expanding the functionality and versatility of your topographic projects.
- **User-Friendly Interface** — Enjoy a straightforward interface that simplifies complex tasks, making it suitable for users at all skill levels.
